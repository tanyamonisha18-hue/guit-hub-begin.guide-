# Chapter 3: Working with Files and Commits

## 3.1 Introduction

Files are an important part of every GitHub repository. A repository can contain different types of files, such as Markdown files, images, documents, and code files.

GitHub also keeps track of the changes made to these files. This makes it easier to understand how a project has changed over time.

In this chapter, you will learn how to:

- Add files to a repository
- Edit files
- Delete files
- Understand commits
- Write commit messages
- View commit history
- Compare changes
- Use Markdown files in GitHub

---

## 3.2 Adding Files to a Repository

You can add files to a GitHub repository in different ways.

You can:

- Create a new file directly on GitHub
- Upload a file from your computer
- Add files using Git on your computer

For a beginner, creating or uploading files directly on GitHub is the easiest method.

---

## 3.3 Creating a New File

You can create a new file directly inside your repository.

Follow these steps:

1. Open your GitHub repository.
2. Select **Add file**.
3. Select **Create new file**.
4. Enter the name of the file.
5. Add your content.
6. Enter a commit message.
7. Select **Commit changes**.
