This guide explains the basics of GitHub and how to create and manage repositories.

It is designed for beginners who are new to GitHub and Markdown.

- What Git and GitHub are
- How GitHub repositories work
- How to create and manage repositories
- How to add and edit files
- How commits work
- How Markdown can be used for documentation
